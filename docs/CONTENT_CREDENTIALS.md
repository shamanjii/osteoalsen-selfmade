## 📊 SEO Best Practices

### On-Page SEO:
1. **Title Tag**: Max. 60 Zeichen, Primäres Keyword am Anfang
2. **Meta Description**: 150-160 Zeichen, CTR-optimiert mit ✓ und ⭐
3. **H1**: Nur EINE H1 pro Seite, enthält Primäres Keyword
4. **H2-H6**: Strukturiert, enthalten Sekundäre Keywords
5. **Interne Links**: Mindestens 3-5 pro Seite zu relevanten Inhalten
6. **Alt-Tags**: Beschreibend mit Keywords
7. **URL-Struktur**: Kurz, beschreibend, mit Keywords

### Schema Markup verwenden:
- LocalBusiness Schema ✅ (bereits implementiert)
- MedicalBusiness Schema ✅ (bereits implementiert)
- FAQPage Schema ✅ (für FAQ-Sections)
- BreadcrumbList Schema ✅ (für Navigation)
- Person Schema (für Über Mich)
- Review Schema (für Testimonials)

### Page Speed:
- WebP Bilder verwenden
- Lazy Loading für Bilder
- Minimierte CSS/JS
- Critical CSS inline
